# Design system direction

## Purpose

Give the product a consistent, polished analytics interface. This is a starting direction; detailed tokens should be approved in the design-system task before implementation.

## Brand anchors

- Deep navy: `#18324B`
- Teal: `#14A38B`
- Warm gold: `#E5A93D`
- Source assets: `assets/brand/logo.svg` and `assets/brand/mark.svg`

Use these as brand accents, not as the complete chart palette. Chart series need a color-blind-aware palette and should not rely on color alone to convey meaning.

## Interface principles

- Put the user's question, data scope, and active result in clear view.
- Prefer a calm, professional business interface with generous spacing and restrained decoration.
- Show exact numbers in tooltips and provide an accessible table or equivalent data view.
- Make the active dataset/session visible. Explain and confirm before replacing it with a different data scope.
- Support keyboard use, responsive layouts, readable contrast, and clear loading, empty, clarification, error, and success states.

## Open design choices

Typography, spacing/radius/shadow tokens, light/dark mode, chart colors, responsive breakpoints, and component conventions are open. Decide and record these before adding UI implementation patterns.
